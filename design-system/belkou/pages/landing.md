# Landing (`/`) — overrides

Follow Master unless noted.

## Hero
- Brand (`Belkou`) is the first hero-level signal (tracking uppercase)
- One headline, one support line, one CTA pair
- Full-bleed mesh / grid atmosphere (no inset cards, no floating badges)
- Light trust line (ratings + student count) sits below CTAs only

## Section order
1. Hero (with Navbar overlay)
2. Trending courses (`CoursesSection` — catalog grid)
3. Impact stats (`TrustStrip`)
4. Services (`ServicesSection`)
5. Upcoming courses (`UpcomingCourses`)
6. How it works (`HowItWorks`)
7. Testimonials (`Testimonials`)
8. Final CTA (`CTA`)
9. Footer

## Motion
- Hero: staggered FadeIn via Framer Motion (≤ 300–500ms)
- Lower sections: `FadeIn` on enter viewport
