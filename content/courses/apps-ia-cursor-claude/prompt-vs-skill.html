Session 1 — Prompt vs Skill


Gen yon diferans ant yon Prompt ak yon Skill, menm si anpil moun itilize yo tankou se menm bagay. Si w konfonn yo, ou pral pase tan ap kopye/kole menm enstriksyon yo chak fwa — olye de bati yon bibliyotèk ki fè AI a travay tankou yon pwofesyonèl.


Nan VibeCoding, ou pa sèlman ap « mande AI yon bagay ». Ou ap aprann kijan pou w bay AI a yon wòl, yon misyon, ak yon estanda kalite — pou li konpòte l tankou yon CTO, UI Designer, Backend Engineer, DevOps, QA, oswa Product Manager.


Objektif Chapit la


Lè ou fin etidye chapit sa a, ou pral kapab :

  • Eksplike diferans ki genyen ant yon Prompt ak yon Skill
  • Rekonèt lè yon demann twò kout pa ase pou travay pwofesyonèl
  • Li estrikti yon Skill (Role, Mission, Rules, Output…)
  • Konprann poukisa yon Skill Library (15–20 Skills) chanje fason ou travay
  • Telechaje Skill Library a nan onglet Fichiers kou a epi kòmanse itilize l


1.1 Kisa yon Prompt ye?


Yon prompt se yon sèl enstriksyon ou bay AI a.


Li ka kout :

Analize this project React e optimize performances.


Oswa pi long :

Ou se yon Senior Software Engineer...
Analize proje sa konpletman...
epi apre fe yon raport...


Men nan tou de ka yo, se jis yon mesaj ou voye. Lè sesyon an fini, ou souvan dwe rekòmanse — kopye/kole ankò, eksplike kontèks ankò, mete règ ankò.


Prompt = demann. Li itil, men li pa yon sistèm.


1.2 Kisa yon Skill ye?


Yon Skill se yon pakè konplè ki fè AI a konpòte l tankou yon espesyalis nan yon domèn.


Yon Skill anjeneral gen ladan :

  • Role — ki ekspè AI a ye
  • Mission — sa li dwe akonpli
  • Objectives — rezilta klè
  • Context — kontèks pwojè / pwodui
  • Rules — sa ki obligatwa
  • Constraints — sa li pa dwe fè
  • Thinking Process — kijan li panse anvan li aji
  • Workflow — etap yo
  • Tasks — travay konkrè
  • Output Format — fòma livrezon
  • Quality Checklist — kritè kalite anvan « fini »


Li pi estriktire pase yon prompt senp — e li ka reyitilize chak fwa ou bezwen menm nivo kalite.


1.3 Egzanp — Prompt vs Skill (UI)


❌ Prompt kout

Improve this UI.

Sa kout anpil. AI a ka chanje koulè aleatwa, kraze brand ou, oswa « redesign » san kritè.


✅ Skill (estrikti)

ROLE
You are a Senior Product Designer,
Senior UX Researcher,
Apple HIG Expert,
Material Design Expert,
Accessibility Expert.

MISSION
Audit the complete interface.

OBJECTIVES
Improve:
- Typography
- Spacing
- Buttons
- Cards
- Responsive
- Accessibility
- Visual Hierarchy
- Navigation

RULES
- Never redesign randomly.
- Preserve brand identity.
- Think mobile first.

OUTPUT
Generate:
- UI Score
- UX Score
- Accessibility Report
- Color Palette
- Typography Scale
- Component Improvements
- Priority Roadmap


Ak Skill sa a, AI a pa « jis reponn ». Li jwe yon wòl, swiv règ, epi livrezon gen fòma ak kalite.


1.4 Skill pa sèlman « pi long prompt »


Yon Skill pa sèlman reponn kesyon yo. Li rekòmande AI a pou li konpòte l tankou yon :

  • CTO — desizyon teknik, priorite, risk
  • UI / Product Designer — layout, hiérarchie, brand
  • Backend Engineer — API, done, sekirite
  • DevOps — deploy, env, monitoring
  • QA Engineer — tès, regresyon, edge cases
  • Product Manager — scope, roadmap, kritè akseptans


Sa se diferans ki genyen ant « mande yon favor » ak « anboche yon espesyalis pou yon misyon ».


1.5 Poukisa Skill Library chanje jwèt la


Lè w nivo ak SKILL olye de PROMPT sèlman, ou evite :

  • Kopye / kole menm tèks la chak jou
  • Fè 100 demann pou jwenn yon sèl rezilta ou bezwen an
  • Pèdi tan ap re-eksplike règ, brand, ak fòma chak fwa
  • Rezilta ki « bèl yon fwa », men pa konsistan


Si w vle travay tankou yon pro nan VibeCoding, fok ou gen yon Skill Library ki gen ant 15 a 20 Skills — yon zouti pou chak wòl / chak kalite travay.


1.6 Ki kote pou jwenn Skill Library a?


Nan kou Aprann VibeCoding sa a :

  1. Ale nan leçon an (paj aprantisaj)
  2. Louvri onglet Fichiers (Téléchargements)
  3. Telechaje Skill Library la
  4. Itilize Skills yo nan Cursor / Claude pandan w ap bati MVP ou a


Konsèy : pa eseye memorize tout Skills yo yon sèl fwa. Chwazi 1–2 selon travay jodi a (eg. UI audit, API design, QA), itilize yo, epi ajoute plis nan bibliyotèk ou a.

1.8 Checklist — èske sa se Prompt oswa Skill?


Anvan ou voye yon bagay bay AI a, mande tèt ou :

  • Èske se yon sèl demann san règ / san fòma? → Prompt
  • Èske mwen bay Role + Mission + Rules + Output? → Skill (oswa yon draft Skill)
  • Èske mwen pral bezwen menm bagay la ankò demen? → Sove l kòm Skill nan bibliyotèk ou a
  • Èske mwen vle AI a jwe yon wòl espesyalize (Designer, QA, CTO…)? → Itilize yon Skill, pa yon fraz 5 mo
  • Èske mwen deja telechaje Skill Library nan onglet Fichiers? → Wi / Non — fè l kounye a si ou poko


Apre ou fini li


Lè ou fin li modil sa a :

  1. Telechaje Skill Library a nan onglet Fichiers
  2. Chwazi yon Skill (eg. UI / UX audit)
  3. Aplike l sou yon ti pati MVP ou a nan Cursor
  4. Konpare rezilta a ak yon prompt kout « Improve this UI » — w ap wè diferans lan
  5. Mark leçon sa a kòm terminée epi kontinye


Souke : Prompt se demann. Skill se espesyalis. Pro VibeCoding bati yon bibliyotèk Skills — yo pa rete nan kopye/kole.


Poze kesyon ou yo nan forum kou a si ou pa jwenn fichye Skill Library a nan Fichiers.
